# Práctica QGIS – Muestreo de castores

Práctica demostrativa de un estudio ficticio de muestreo de castores y su integración en un sistema de información geográfica con QGIS. Incluye una aplicación Python con formulario para introducir datos en una base de datos SQL y generar un CSV listo para importar en QGIS.

> **Nota:** todos los datos utilizados son ficticios y se emplean únicamente con fines demostrativos.

## Vídeo explicativo

[Enlace al vídeo de YouTube (no listado)](https://www.youtube.com/watch?v=ZCpF68QjvpQ)

El vídeo incluye marcas de tiempo en la descripción para poder ver solo las partes de interés.

## Requisitos

- Python 3.11 o superior
- QGIS 3.x
- SQLite (incluido con Python)
- Sin dependencias externas adicionales
